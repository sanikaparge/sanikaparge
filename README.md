### Project overview

A library management application designed to manage books, members, and book-issuing operations.

The application uses Flask for backend functionality and PostgreSQL for persistent data storage.

Docker and Docker Compose are used to package and run the application's services.

### Technical architecture

```text
             USER
               |
               v
       WEB APPLICATION
               |
               v
        FLASK BACKEND
               |
               v
         POSTGRESQL
```

### What this project demonstrates

- Containerizing an application with Docker.
- Configuring services with Docker Compose.
- Connecting a Flask backend to PostgreSQL.
- Organizing frontend, backend, and database components.
- Working with environment configuration.
- Understanding application and database connectivity.
- Practising container lifecycle management.
- Exploring deployment on cloud infrastructure.

<summary><b>PROJECT 02 — KubeSentinel Kubernetes Reliability Lab</b></summary>

<br />

<div align="center">

<img src="https://img.shields.io/badge/STATUS-IN%20PROGRESS-F59E0B?style=for-the-badge" alt="Project in progress" />

<img src="https://img.shields.io/badge/PLATFORM-KUBERNETES-326CE5?style=for-the-badge&logo=kubernetes&logoColor=white" alt="Kubernetes platform" />

### Project overview

KubeSentinel is a practical Kubernetes lab focused on workload health, replica management, resource controls, and application recovery.

The goal is to explore how Kubernetes maintains the desired state of applications and how to investigate common workload failures.

### Technical areas

- Pod and Deployment manifests.
- ReplicaSets and replica management.
- Liveness and readiness probes.
- CPU and memory resource requests and limits.
- Service discovery and connectivity.
- Pod failure diagnosis.
- Application recovery and troubleshooting.
- Kubernetes YAML configuration.

### Conceptual workload flow

```text
          APPLICATION IMAGE
                  |
                  v
              DEPLOYMENT
                  |
                  v
              REPLICASET
                  |
          +-------+-------+
          |       |       |
          v       v       v
        POD-1   POD-2   POD-3
          |       |       |
          +-------+-------+
                  |
                  v
               SERVICE
```
